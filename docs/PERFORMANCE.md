# 性能验证记录与口径

当前硬件记录见 `evidence/graphics-adapters.json`：实际 GPU 为 RTX 4060 Laptop GPU，同时存在两个虚拟显示适配器。不能把虚拟适配器名称当作实际渲染硬件。测量使用本机原有驱动和图形设置，不修改系统或驱动配置。

采集工具是经摘要校验的 PresentMon 2.6.0 独立程序。它通过外部 ETW 采集目标 PID 的 Present 事件，不注入客户端，不记录输入。原始 CSV、运行元数据和工具输出均保留。计算游戏主交换链的 `MsBetweenPresents`；平均 FPS 为 1000/平均帧时间，P99 使用线性插值，保留所有有效帧，不删除卡顿或挑选较好轮次。至少 115 秒且 1000 帧才具备两分钟测试资格。

每种条件三轮、每轮 120 秒，单轮另有 5 秒预热。比较使用全部三轮平均 FPS 的算术均值及全部三轮 P99 的算术均值，同时保留逐轮结果。目标为平均 FPS 下降不超过 3%，P99 恶化不超过 10%。`tools/compare_performance.py` 会检查地图、角色位置、图形配置及基线 DLL 状态；镜头仍需要截图人工核对。固定镜头结果只代表固定场景，不能替代移动路线或长时间运行测试。

用户明确要求“性能问题不需要测了 直接干活”。因此不再开展 0.1.2 正常密度与受控前台压力包的三轮对照或同路线移动测试，不声明平均 FPS 下降 ≤3% 或 P99 恶化 ≤10% 已通过。已有采集作为有限历史观测保留，不能拼接不同条件得出性能结论。
