# 扩充快照安装说明

本包为 **0.1.5 有限快照正式版**，包含 23,439 条真实匿名样本、476 个原始地图编号。当前固定 DLL 已通过中英语实际阅读、标题／死亡／跨图／正常重启各 3 轮，以及原生缓存自然清空后的恢复阅读。两个指定新增样本均已在完整包原位读到。它不是服务器全量数据，也不保证无缺口全地图。详见 `verification/validation.json`。

本包的条数、实际覆盖地图与验收状态以包根目录的 `COVERAGE.json`、`data-provenance.json` 和 `verification/validation.json` 为准。区域样本、地图文件和服务器全量是不同概念。标注“开发版”或“未完成全地图”时，请保留该说明，不要转述为全量成品。

仅针对实际核对的 Windows x64 Steam App 1.17.2 / Regulation 1.17.3、EXE 2.7.2.0；EXE SHA-256 为 `F9118FEA2CFD8FA3901E8060BFADB1552CB2471771DED8A5B662C4E298FFB328`。其他版本会停止回放。需另行安装 [ME3 0.13.0（官方发布页）](https://github.com/garyttierney/me3/releases/tag/v0.13.0)，包内不含游戏或加载器。

## 解压与启动

1. 将整个包解压到新的独立文件夹，例如 `E:\Mods\EROfflineMessages`。保留配置、启动脚本及 `natives` 的相对位置，不要覆盖游戏文件或其他 Mod。
2. 保持 Steam 运行，通过菜单正常退出当前游戏。不要替换正在加载的 DLL。
3. 本次测试机器可双击 `Launch.cmd`。其他机器从命令行执行 `Launch.cmd "完整路径\me3.exe"`。脚本显式调用加载器，避免旧 `.me3` 文件关联。
4. 也可执行 `me3.exe launch --game eldenring --profile "完整路径\EROfflineMessages.me3"`。配置强制脱机，不指定替代存档；继续可用于原版的角色。
5. 数据启动时读取一次，放在 DLL 旁并命名为 `EROfflineMessages.pack.json`。角色载入后等待数秒。原版空间密度规则会限制同时可见的标记，不保证一处所有样本同时显示。

## 已有配置合并

先复制现有配置到新文件，保持 `start_online=false`，加入一次 `[[natives]]`，其 `path` 指向本包的 DLL。保留 DLL 旁的数据文件。不要重复添加同一 DLL，也不要同时添加另一份旧版回放器。其他 Mod 的兼容性必须另行验证；本包的原版独立测试不能代替组合测试。

在配置顶层找到并设置 `start_online = false`，不要在某个表内部新增这一行。然后仅追加一次以下原生模块条目，并将路径改为实际解压位置：

```toml
[[natives]]
path = 'E:\Mods\EROfflineMessages\natives\EROfflineMessages.dll'
```

## 排错

查看 `natives/EROfflineMessages.log`。`Loaded` 是已加载，`Waiting` 是等待脱机角色，`Registered` 只表示登记；这些日志单独不能证明能看到或阅读。`Disabled` 会给出停止原因。版本/签名不匹配、反作弊进程存在、数据损坏或重复加载时先正常退出游戏，核对实际启动配置与文件，再处理原因。

检查包内 `COVERAGE.json` 是否包含当前地图。无样本的地图不会凭空出现留言；附近选择和原版密度准入也会影响标记数量。更换数据、DLL 或配置后正常重启，不要编辑存档或强制结束进程清缓存。

## 卸载与还原

正常退出游戏后停止使用本配置，恢复原有启动方式；合并过配置时移除本 DLL 条目。安装没有替换游戏文件，也没有直接编辑存档。游戏自身可能自动保存谏言缓存，清理由游戏处理。源码和构建步骤位于 `source`，第三方许可证位于 `licenses`，逐文件校验在 `SHA256SUMS.txt`。
