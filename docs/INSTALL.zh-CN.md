# 艾尔登法环离线谏言 0.1.3 — 真实客户端有限快照

本包通过原版地面标记、交互提示和阅读界面，回放 **103 条正常官方客户端接收记录**：近林洞窟地图 41 条，附近开放世界区块 m60_42_37_00 为 62 条。它不是服务器全量，也不覆盖全地图。只有一条完成了逐项在线/离线文字、评价、位置对照；整批的逐条验证情况见 `verification/validation.json`。

数据保留客户端收到的区块坐标、区域、原版句式/词语编号及评价快照，运行时由游戏按自身语言显示。包含 17 条双句谏言；不包含账号、姓名、外观、手势或玩家幻影，不上传评价。构造测试包留在源码 `source/data/` 中，来源单独标注，不混入默认回放包。

## 安装与启动

1. 使用 Steam 正版游戏及单独安装的 **ME3 0.13.0**。本包不包含加载器。实际适配 App 1.17.2 / Regulation 1.17.3、EXE 2.7.2.0；EXE SHA-256 必须为 `F9118FEA2CFD8FA3901E8060BFADB1552CB2471771DED8A5B662C4E298FFB328`，版本不符会拒绝回放。
2. 将整个目录解压到新的独立文件夹，例如 `E:\Mods\EROfflineMessages`，无需放进 Game。不要覆盖游戏资源、其他 Mod、现有配置或备份。
3. 保持 Steam 运行，从游戏菜单正常退出当前游戏。双击本包 `Launch.cmd`。默认显式调用 `F:\Steam\steamapps\common\ELDEN RING\Game\bin\me3.exe`，避免本机旧 `.me3` 文件关联。
4. 若 ME3 在其他位置，在本目录命令提示符执行 `Launch.cmd "C:\你的目录\me3.exe"`，或编辑脚本中的默认路径。也可用 ME3 完整路径执行 `launch --game eldenring --profile "本包完整路径\EROfflineMessages.me3"`。
5. 确认标题显示脱机模式后，继续原版角色。此配置仅加载本 DLL，不加载剑心修罗或其他资源，不指定替代存档。进入近林洞窟或其洞口附近区块，等待数秒再查看地面标记。交互重叠时使用原版切换操作选择谏言。

不要经 `start_protected_game.exe` 加载此回放配置。EAC 存在或无法确认脱机时，本 Mod 拒绝或暂停回放；等待原版保护进程正常退出，不要改反作弊文件或关闭安全软件来绕过。工具不直接打开或编辑存档；正常游玩的自动保存与原版缓存持久化仍会发生。

## 合并已有配置

先把已有配置复制成新文件，保留原件。在副本保持 `start_online = false`，只增加一次以下条目，替换为本包 DLL 的实际绝对路径：

```toml
[[natives]]
path = 'E:\Mods\EROfflineMessages\natives\EROfflineMessages.dll'
```

保留 DLL 旁 `EROfflineMessages.pack.json`，不要通过另一配置再次加载复制的 DLL。进程级保护会拒绝重复实例，但配置仍应只有一个条目。目前实测为独立原版环境，不声明与其他 Mod 兼容。

## 日志与排错

日志在 `natives/EROfflineMessages.log`。Loaded、Ready、Registered 分别表示载入、门禁/Hook 就绪、完成登记，都不单独证明画面可见或可读。Disabled 后查看拒绝原因，不要删版本校验或猜偏移强行加载。

- 无日志：检查显式 ME3 路径、DLL 路径及目录写入权限，不使用旧文件关联。
- Ready 但无标记：核对当前地图是否属于这两个编号，等待载入稳定与分帧登记；原版空间密度限制可能使显示数少于缓存数。
- CacheBudget 等待：Mod 自设缓存预算暂满，0.1.3 每秒至多重试一次，等待原版清理后继续，不删除游戏节点。刚正常联网后可能带有旧缓存；具体等待取决于原版生命周期。不要直接编辑存档清缓存。
- 数据错误：恢复包内原始 JSON。未知字段、重复本地消息键、非法坐标等会拒绝加载。数据仅启动时读取。
- 替换 DLL 或数据前正常退出游戏；不支持热卸载或运行中替换。

## 卸载、校验与源码

正常退出，停止使用此独立配置，恢复原来的启动方式。之后可移走本目录；安装没有替换游戏原文件。合并配置的用户只需从副本移除本 Mod 唯一条目。旧回放缓存由游戏自行清理，不通过存档编辑删除。

逐文件 SHA-256 在 `SHA256SUMS.txt`。可用 PowerShell 的 `Get-FileHash .\natives\EROfflineMessages.dll -Algorithm SHA256` 核对 DLL；ZIP 自身的摘要另附为同名 `.zip.sha256` 文件。完整源码和离线构建步骤在 `source/`、`source/docs/BUILD.md`；第三方许可证在 `licenses/`。游玩依赖是游戏与 ME3；Python、.NET 和研究库仅供开发。原始游戏资源、原始文本表、私人采集缓存及代理备份均不在包内。

## 实测边界

完整结果见 `verification/TEST_REPORT.md` 和机器可读记录，明确区分 0.1.1、0.1.2 与 0.1.3。首条真实样本已完成原版在线阅读、正常退出、脱机提取、原位回放阅读，文字与总评价一致；同批其余记录具有同一接收来源，但不等于每条均逐项核对。仅声明实际核对的游戏版本。

用户取消后续性能测试及一小时稳定性测试，因此不声明 FPS/P99 达标或一小时通过。其他语言、Mod 兼容性和覆盖范围不得超出验证记录。运行时始终离线，正常游玩不需要服务器，也不会更新或上传评价。

当前 0.1.3 已有简体中文与英语双句原版阅读截图，英语检查从 ZIP 解压目录实际启动。标题继续与死亡恢复各 3/3 由测试用户确认。最终交付的运行时文件与该测试包逐项校验一致。
